# Contributing

Vantage is a proprietary project (see [LICENSE](LICENSE)). The repository is public for
portfolio purposes only.

- **Pull requests are not accepted.** Any code submitted will be closed without review, so that
  the ownership of the Work stays with a single author.
- **Bug reports are welcome** as issues (a rendering glitch, an accessibility problem, a device
  where the page fails). Describe the problem and the device; do not attach code.
- **Security issues:** follow [SECURITY.md](SECURITY.md), never a public issue.

By opening an issue you agree that any suggestion it contains may be used freely by the author,
without obligation or compensation.
